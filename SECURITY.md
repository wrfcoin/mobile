# Security policy

This policy covers the WRFCoin public testnet.

Report suspected vulnerabilities privately to **security@wrfcoin.com**.
Please do not open public issues for vulnerabilities or post exploit details.
The current policy is at <https://wrfcoin.com/security>.

Include the affected component and version, impact, and safe reproduction steps.
Never send recovery words, private keys, credentials, or precise location data.
No bug bounty or payment is promised.
